TEC Route Lookup

v1.2

Tower Enroute Control routes, fetched fresh from the FAA's own preferred-routes database on every server request — no third-party or simulation-network data involved.

Leave unchecked for the standard/West configuration.
Aircraft classification checkboxes are applied where the FAA data encodes it (either as letters baked into the altitude field, e.g. "JM110PQ70", or as plain-language restrictions in the aircraft/notes field); check as many as apply. Routes that carry no classification info for this pair are always shown, since they apply regardless of aircraft type. Landing East filters to route variants explicitly marked for LAX's East configuration when both exist; if only one variant exists for a pair, it's shown regardless of the checkbox. Departure/Destination accept either the 4-letter ICAO code (e.g. KSBA) or the 3-letter FAA identifier (e.g. SBA) and always display as the 4-letter form. Always cross-check against the current Chart Supplement or your EFB before filing.
